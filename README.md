# Bank Management System

A Bank Management Syste developed in C++ that simulates core banking operations through a console-based application. The project is designed using Object-Oriented Programming (OOP) principles to manage customer accounts, process transactions, and maintain banking records efficiently.



## Project Overview

This application provides a simple banking environment where users can perform essential banking activities such as account creation, deposits, withdrawals, and balance inquiries. The project demonstrates how C++ can be used to build real-world management systems while applying strong programming fundamentals.


## Key Features

✔ Create and manage customer bank accounts
✔ Deposit money securely into accounts
✔ Withdraw money with balance validation
✔ Check account balance instantly
✔ View customer account details
✔ Menu-driven user interface for easy navigation
✔ Record and manage multiple customer accounts
